# Декодирование движений кисти по ЭМГ — кейс AIRI (команда Pulse)

Решение задачи хакатона «Научная орбита» на платформе StackMoreLayers: по 6 каналам ЭМГ (500 Гц) предсказать 20 углов суставов кисти.

- **Итог на скрытом тесте этапа 2: wMAE = 0.0821 рад — 1-е место** (2-е место 0.1073). Отправлен `final_v4`.
- **Текущий результат:** weighted MAE ≈ **0.0889 рад** на leave-one-day-out CV (v4: два раунда транздуктивной дистилляции; учитель v2 — 0.091). Бейзлайн организаторов (Ridge) — 0.346, константа — 0.375.
- **Подробности:**
  - **[HANDOFF.md](HANDOFF.md)** — как устроено решение, правила, как запускать, чеклист финала. Начинать лучше с него.
  - **[CHEATSHEET.md](CHEATSHEET.md)** — шпаргалка к защите: всё решение коротко.
  - **[EXPERIMENTS.md](EXPERIMENTS.md)** — все 50+ экспериментов: что это, зачем пробовали, какие результаты.

## Результат и потолок

- **0.089–0.091 по ощущениям близко к потолку для этих данных.** Около 100 экспериментов и 9 принципиально разных веток сходятся к ~0.095 на одну модель и ~0.091 на ансамбль. Последние улучшения на уровне шума CV (±0.0005–0.001). Ветки: свёрточные, рекуррентные и трансформерные сети, деревья, kNN, низкоранговые декодеры, сессионная нормировка, самообучение.
- **Неустранимая часть — ~0.012: статичные смещения позы в конкретной сессии.** Это неактивные пальцы и открытая ладонь. Если бы смещение было известно, ошибка была бы 0.0795. По ЭМГ его не извлечь: все попытки, включая нормировку по сессии с идеальным знанием сессий, хуже. Похоже на калибровку перчатки, а не на мышечный сигнал.
- **Остальное — трекинг движения.** Он ограничен объёмом данных (10 сессий × ~6 минут), 6 каналами на 20 углов и сцепленностью пальцев.
- **Сильно сдвинуть результат могли бы только** углы части тестовой сессии (их не дают) или больше данных того же человека и железа.
- **В метрике соревнования** отставание на 0.006 от гипотетического лидера стоит ~0.34 балла из 10. Главные риски теперь — назначение действий и технические ошибки на финале.

## Структура

```
common.py          загрузка данных, метрика (точная копия правил), фолды по дням
feats.py           признаки: лог-огибающие, корреляции, tangent space, сырой сигнал
nn.py              регрессор (TCN + BiGRU/BiLSTM/Transformer) + CV-скрипт
clfnn.py           CNN-классификатор действия по всей записи + CV-скрипт
clf_features.py    признаки записи для логистической регрессии
combine.py         назначение действий (венгерский алгоритм) + честная симуляция теста
final.py           полный пайплайн: train → классификация → регрессия → CSV
gbm_cv.py          альтернативная ветка: LightGBM по лагам (CV)
retr.py            альтернативная ветка: retrieval cross-attention (CV)
sml_api.py         клиент API платформы (статус, лидерборд, отправка)
configs/           конфиги: final_v4.json — актуальный (учитель + 2 раунда студентов), v3 — 1 раунд, v2 — только учитель
models/            предобученные на всех 80 записях модели (кэш для final.py)
experiments/       скрипты исследований (EDA, бейзлайны, ансамблирование)
results/           таблицы всех экспериментов
figures/           графики
docs/case/         материалы кейса: PDF, правила, описание данных
reference/         бейзлайн организаторов
```

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Для GPU поставьте torch под свою версию CUDA, например `pip install torch --index-url https://download.pytorch.org/whl/cu126`.

## Данные

Скачайте архив с вкладки «Данные» соревнования и распакуйте его в `data/`:

```
data/train/{signals,targets}/rec_*.npy, data/train/metadata.csv, data/train/angle_info.json
data/phase1_test/, data/phase1_sample_submission.csv
data/test/, data/phase2_sample_submission.csv      ← появятся на этапе 2
```

## Финальный сабмит (этап 2)

```bash
python final.py --test-dir data/test --template data/phase2_sample_submission.csv \
    --out outputs/phase2_final.csv --config configs/final_v4.json --model-dir models
```

- На GPU это занимает ~45–70 минут. Модели учителя берутся из `models/` без переобучения. При запуске обучаются только части, которые используют тестовые сигналы: классификатор, SSL-модели, псевдо-лейблинг и студенты.
- Быстрый запасной вариант без студентов — `configs/final_v2.json`, ~25 минут.
- Рядом с CSV сохраняются `*.actions.csv` (какое действие назначено каждой записи) и `*.probs.npy`.
- **На этапе 2 разрешена одна успешная отправка.** Перед ней проверьте `actions.csv`: должно получиться 4 записи на каждое из 8 действий, с высокой уверенностью.

Отправка через API (токен из Settings → API access кладётся в `~/.sml_token`, в репозиторий его не коммитим):

```bash
python sml_api.py status
python sml_api.py leaderboard
python sml_api.py submit outputs/phase1.csv 838                       # этап 1 (синтетика)
python sml_api.py submit outputs/phase2_final.csv 839 --i-am-sure-final  # этап 2, ОДИН РАЗ
```

## Воспроизведение CV

```bash
python nn.py --gru 2 --seeds 2 --tag lstm_env                 # регрессор, leave-one-day-out
python nn.py --gru 2 --feat envraw --chdrop 0.15 --tag lstm_raw
python clfnn.py --seeds 3 --tag clf                            # классификатор действия
python combine.py --oof outputs/oof_lstm_env.npy --probs outputs/clfnn_clf.npy   # end-to-end оценка
PYTHONPATH=. python experiments/eda.py                         # EDA и бейзлайны
```

Одна CV-конфигурация регрессора (7 фолдов × 2 сида) идёт ~5–10 минут на одной GPU.
